<h2 id="javascript">🧠 JavaScript e interatividade</h2>

<p>
    Durante o desenvolvimento, foram utilizados conceitos como manipulação do DOM, eventos, funções, módulos JavaScript e manipulação de arrays.
</p>

<p>
    Entre os métodos utilizados estão <code>filter()</code>, <code>sort()</code> e <code>forEach()</code>, aplicados principalmente na criação dos filtros, busca e ordenação dos produtos.
</p>

<p>
    O código JavaScript também foi separado em diferentes arquivos para organizar as responsabilidades da aplicação:
</p>

<ul>
    <li><code>main.js</code> — inicialização das funcionalidades</li>
    <li><code>filtros.js</code> — filtros e busca de produtos</li>
    <li><code>sort.js</code> — ordenação dos produtos</li>
    <li><code>carrinho.js</code> — funcionalidades do carrinho</li>
    <li><code>shared.js</code> — elementos compartilhados entre os módulos</li>
</ul>
